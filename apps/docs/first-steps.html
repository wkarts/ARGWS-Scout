ASSISTENTE DE UTILIZAÇÃO

Sua primeira coleta e publicação

Aprenda em poucos passos a buscar dados de uma página pública, executar a coleta e publicar um resultado pelo WhatsApp usando a Connect|API.

1. Acesse e proteja sua conta

Entre com seu e-mail e senha; quando solicitado, configure o aplicativo autenticador e guarde os códigos de recuperação. Quem foi convidado define a própria senha no link enviado por e-mail.

2. Crie uma instância

No Manager, abra Instâncias → Nova instância. Nome de exemplo: Monitoramento de site. Agrupe suas fontes dentro dela.

3. Cadastre uma fonte

Acesse a instância e selecione Fontes → Adicionar fonte. Preencha:

  1. Nome: Página de exemplo
  2. URL: https://example.org
  3. Mecanismo: HTTP
  4. Hosts permitidos: example.org
  5. Seletor opcional: h1
  6. Respeitar robots.txt: Sim

Use apenas páginas que você está autorizado a consultar. O Scout não deve copiar vídeos protegidos, contornar login, DRM, paywalls ou limites do site.

4. Inicie a coleta

Abra Execuções → Nova execução, escolha a fonte e envie para a fila. Acompanhe o status e abra a execução concluída para ver os dados extraídos. Páginas dinâmicas podem exigir o mecanismo de navegador.

5. Configure Connect|API

A conexão global é definida pelo operador no servidor. Abra Connect|API, crie sua própria instância WhatsApp neste espaço e faça o pareamento. Nenhum usuário precisa informar URL ou token administrativos nesta tela.

6. Publique o resultado

Em Execuções, abra a coleta concluída e escolha Publicar pelo WhatsApp. Informe o número com país e DDD, revise a mensagem e confirme o envio. Não repita a publicação quando o resultado do envio for indeterminado sem antes consultar o histórico.

7. Automatize quando estiver funcionando

Cadastre uma regra em Agendamentos para repetir a coleta. Configure um webhook apenas se precisar notificar outros sistemas.
